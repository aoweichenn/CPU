# 计算机硬件从零到整机

这本书是独立的计算机组成原理入门卷。它不作为操作系统书的章节，也不搬运 OS 书里的补充材料。正文从最底层的电、二极管和受控开关开始，沿着“逻辑门 -> 组合逻辑 -> 反馈与触发器 -> 时钟与复位 -> 寄存器和状态机 -> 算术电路 -> ALU -> 数据通路 -> 控制器 -> 最小 CPU -> 主存/总线/I/O/整机”的路线，把硬件链路讲成一条连续推导。

## 目录

- `source/latex/`：正式 LaTeX 书稿。
- `source/latex/chapters/`：正文章节。
- `materials/`：后续素材和草稿。
- `labs/`：后续硬件模拟实验。
- `reports/`：读书报告和实验报告。
- `results/`：实验输出。
- `tools/`：本书专用工具。
