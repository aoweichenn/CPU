# 计算机硬件从零到整机

这本书是独立的计算机组成原理入门卷。它不作为操作系统书的章节，也不搬运 OS 书里的补充材料。正文从最底层的电、二极管和受控开关开始，把硬件链路压缩为四个厚章：电平、开关、逻辑门与组合电路；状态、时钟与同步边界；数值、ALU、数据通路与控制器；CPU、经典芯片与整机硬件。

## 目录

- `source/latex/`：正式 LaTeX 书稿。
- `source/latex/chapters/`：正文章节。
- `materials/`：参考资料与素材归档。
- `labs/`：硬件模拟实验。
- `reports/`：读书报告和实验报告。
- `results/`：实验输出。
- `tools/`：本书专用工具。
