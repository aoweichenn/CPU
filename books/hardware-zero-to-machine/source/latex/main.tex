\part{主板与平台}
\begin{partbridge}
逻辑正确不等于机器可靠。电压会跌、时钟会抖、信号会变形；固件还必须按顺序完成供电、复位、训练和枚举。数据通路回答“数据从哪来到哪去”，控制面回答“谁、按什么规则、在什么时候让这一切发生”。本部分把主板写成一组从皮秒到秒嵌套的电气边界、启动依赖和反馈控制环。
\end{partbridge}

\part{系统扩展与软件边界}
\begin{partbridge}
CPU 再快也要和外部世界交换数据：网络按帧到达，输入设备按事件报告，显示按帧扫描。这些设备各有物理脾气，但接入方式高度一致——队列、描述符、DMA 和完成通知。本部分比较通用外设与 GPU 的队列化事务，最后把程序的出生过程——编译、链接、装载——还原成硬件地址约定。
\end{partbridge}
