# Operating Systems Volume 1

《操作系统第一册》书稿工程。正文从操作系统对象与执行路径进入，依次讨论进程与调度、系统调用、内存管理、设备 I/O、文件系统、网络、安全、持久化与系统观测。计算机组成和硬件实现由独立卷册讲解，本册只在相关机制中说明必要的硬件约束。

## 正文结构

本册当前为 4 部、15 个编号章。正文不设置独立硬件导论，目录直接进入操作系统的对象、机制与边界。

15 个主章是：

1. 操作系统对象、路径与契约
2. 进程、线程与调度
3. 系统调用、权限与内核边界
4. exec、ELF 装载与用户栈
5. 同步、IPC 与锁
6. 虚拟内存与地址空间
7. mmap、page cache 与文件映射
8. 内核内存分配器
9. 设备驱动、中断下半部与 DMA
10. 块设备、I/O 调度与 VFS
11. 文件系统：从磁盘字节到现代设计
12. 套接字、网络协议栈与内核边界
13. 安全、隔离与最小权限
14. 持久化、崩溃一致性与恢复
15. 系统错误、内核崩溃与可观测性

## 目录

- `source/latex/`：LaTeX 正式主稿、章节、前言和附录。
- `source/latex/chapters/`：主线章节，以及与具体主章对应的 Linux 实现补充材料。
- `source/latex/supplements/hardware/`：硬件深讲素材，供计算机组成/硬件补充卷或选读使用，不直接插入第二章后面。
- `source/latex/supplements/pre-os/`：裸机、单片机、中断、定时器和启动前置素材，可作为“从裸机到内核入口”选读。
- `source/latex/supplements/models/`：C++20 模型、x86-64 契约模型、第一阶段验收和硬件到 OS 对象映射，优先归入实践与代码卷。

补充材料的入口在书末“补充材料阅读地图”。主线正文不得把这些 detail 重新作为隐藏章节塞回第二章或第三章后面。
