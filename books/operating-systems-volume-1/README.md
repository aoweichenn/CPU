# Operating Systems Volume 1

《操作系统第一册》书稿工程。正式卷沿用《硬件从零到整机》的因果推导方式：从一台没有操作系统的机器开始，每遇到一个无法靠当前机器解决的问题，才引入一项新的内核能力；直到任务、地址空间、文件、网络端点、安全边界、恢复协议和观测证据共同组成一条完整系统通路。

## 正文结构

本册为 5 部、18 个编号章。章节不按术语并列，而按“旧机器失败—增加最小机制—建立状态对象与不变量—暴露下一项失败”的顺序连接。

1. 从裸机到受控执行：从人工装入、常驻协调程序和强制返回，推导任务、调度、系统调用、程序映像与同步。
2. 地址空间与内存：从地址冲突、重复读取和内核对象分配，推导虚拟内存、文件映射、页缓存与分配器。
3. 异步设备与文件接口：从未来才会完成的设备请求，推导驱动请求对象、DMA、块层和 VFS。
4. 持久对象与网络端点：从可寻址块推导文件系统格式、索引、恢复和现代设计，再把对象与队列模型扩展到网络。
5. 安全、恢复与证据：从越权、掉电和复杂故障，推导最小权限、跨层持久化协议和系统观测。

全书综合路径放在正文之后。读者先获得各层对象和边界，再沿一次文件保存请求复核执行流、地址、文件对象、设备请求与持久化顺序，避免在概念尚未建立时提前给出难以消化的全景图。

## 目录

- `source/latex/`：LaTeX 正式主稿、章节、前言和附录。
- `source/latex/chapters18/`：重构后的 18 章入口、因果桥接和演化素材。
- `source/latex/chapters/`：原有知识单元与 Linux 实现材料，由新章节按主题复用；不得在迁移中删减。
- `source/latex/scripts/restructure_volume.py`：确定性生成演化素材，并把原来的超长文件系统章无损拆成四章。
- `source/latex/supplements/hardware/`：硬件深讲素材，供计算机组成/硬件补充卷或选读使用，不直接插入第二章后面。
- `source/latex/supplements/pre-os/`：裸机、单片机、中断、定时器和启动前置素材，可作为“从裸机到内核入口”选读。
- `source/latex/supplements/models/`：C++20 模型、x86-64 契约模型、第一阶段验收和硬件到 OS 对象映射，优先归入实践与代码卷。

补充材料的入口在书末“延伸阅读说明”。主线章节只引入解决当前问题所必需的材料，避免把独立硬件卷和实验卷整体重复进来。
