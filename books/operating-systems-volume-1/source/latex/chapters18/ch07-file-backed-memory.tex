\begin{statebox}
\textbf{继承的机器。} VMA 表达地址区间策略，PTE 表达当前映射，物理页保存实际字节。
文件内容还没有统一的缓存身份：按描述符读取与按地址缺页可能为同一文件偏移建立两份页面，
共享写、私有复制、截断和回写因而无法遵循同一套失效规则。
\end{statebox}
